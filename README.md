# Kanban Board

A planned client-rendered Next.js application for managing work on a single Kanban board.

## MVP scope

- One board with exactly five renamable columns
- Cards containing a title and details
- Drag-and-drop card movement between columns
- Card creation and deletion
- In-memory dummy data with no accounts or persistence

The application has not yet been scaffolded. Its source will live in `frontend`.

See [AGENTS.md](AGENTS.md) for the complete requirements and [review.md](review.md) for the documentation review.
